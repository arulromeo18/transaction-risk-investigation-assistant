# Transaction Risk Investigation Assistant

**TRACK_ID:** PS6  
**Hackathon Project:** Real-time fraud detection system for banking fraud investigation teams

---

## 🎯 Overview

The Transaction Risk Investigation Assistant is an AI-powered fraud detection system that analyzes banking transactions in real-time, identifies suspicious patterns, and generates professional investigation narratives for human analysts.

**Key Features:**
- ⚡ Real-time analysis with <60 second response time
- 🤖 AI-generated investigation narratives using Google Gemini 3.6 Flash
- 🔍 6 advanced fraud detection algorithms
- 📊 Professional web interface with risk scoring
- 🏦 Pre-loaded customer profiles with realistic transaction data

---

## 🚀 Quick Start

### Prerequisites
- Python 3.11+
- Google Gemini API key ([Get one here](https://aistudio.google.com/app/apikey))

### Installation & Run

```powershell
# 1. Install dependencies
pip install -r requirements.txt

# 2. Set your Gemini API key
$env:GEMINI_API_KEY="your_api_key_here"

# 3. Start the application
python app.py
```

The application will start on **http://localhost:8000** in under 90 seconds.

## 🔍 Fraud Detection Patterns

The system detects 6 types of fraudulent behavior:

### 1. **Velocity Spike Detection**
Identifies unusual bursts of transactions within short time windows.
- **Trigger:** >3 transactions within 1 hour when normal is <2
- **Risk Level:** High (80-90)

### 2. **Geographic Anomaly Detection**
Flags transactions from unusual or high-risk locations.
- **Trigger:** International transactions, especially from high-risk regions
- **Risk Level:** High (75-85)

### 3. **Unusual Merchant Detection**
Identifies new or suspicious merchants.
- **Trigger:** Transactions with merchants outside normal pattern
- **Risk Level:** Medium-High (70-80)

### 4. **Odd Hours Activity Detection**
Flags transactions during unusual times (late night/early morning).
- **Trigger:** Transactions between 1 AM - 5 AM
- **Risk Level:** Medium (60-75)

### 5. **Amount Outlier Detection**
Detects transactions significantly larger than baseline.
- **Trigger:** Amount >3x median or >2x average
- **Risk Level:** High (75-90)

### 6. **High-Risk Category Detection**
Flags high-risk transaction types.
- **Categories:** Cash advances, gambling, crypto, wire transfers >$10k
- **Risk Level:** Medium-High (70-85)

## 🎨 Technical Highlights

### Backend (Python/Flask)
- **Framework:** Flask with CORS support
- **AI Integration:** Google Generative AI (Gemini 3.6 Flash)

- **Data Models:** Pydantic-style dataclasses with validation

- **API Integration:** Fetch API for backend communication

- **Startup Time:** <90 seconds (requirement met)

- **Scalability:** Modular detector architecture for easy expansion

## 🔧 Configuration

### Environment Variables
- `GEMINI_API_KEY`: Google Gemini API key for narrative generation (required for AI features)

### Customization
- **Add Detectors:** Create new detector class in `src/detectors/` implementing `FraudDetector` interface
- **Modify Thresholds:** Adjust risk scores and detection thresholds in individual detector files
- **Add Customers:** Update `data/profiles.json` with new customer profiles
